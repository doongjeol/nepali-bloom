==================================================
BASIC COURSE IN SPOKEN NEPALI - LESSON 5
==================================================

1. VOCABULARY (어휘)
--------------------------------------------------
ali            : a little (조금)
arkho          : another (다른 것, 다음의)
barun          : Barun (인명)
bhaayo         : became / it is enough (되었다 / 충분하다)
dhanyabaad     : thank you (감사합니다)
hernu          : to look, to see (보다)
hunchha        : okay / it is (좋습니다 / 그렇습니다)
jaaű            : let's go (갑시다)
jammaa         : in total (전부, 합계)
kaparaa        : cloth, clothes (옷, 천)
kati           : how much (얼마나)
khusi          : happy (기쁜)
kinmel        : shopping (쇼핑)
lau            : well / okay (자 / 여기요)
lina           : to take / to buy (사러, 가지러)
mahanago       : expensive (비싼)
manchhe        : person (사람)
miTar          : meter (미터)
paisa          : money / paisa (돈 / 화폐 단위)
pasal          : shop (가게)
pasale         : shopkeeper (가게 주인)
pheri          : again (다시)
rupiyaa        : rupees (루피 - 네팔 화폐 단위)
sasto          : cheap (싼)
tayaar         : ready (준비된)


2. PART I: DIALOGUE (대화문)
--------------------------------------------------
(a) 쇼핑 가기
1. namaste ! / namaste !
2. kahãã jaane ? / kinmel garna bajaar jaane.
   (어디 가세요? / 쇼핑하러 시장에 가요.)
3. ke kinne ? / mero laagi kaparaa kinne.
   (무엇을 사나요? / 저를 위한 옷을 살 거예요.)
4. ekai chhin parkhanus, ma pani jaane. / hunchha, jaaű.
   (잠깐만 기다리세요, 저도 갈게요. / 좋아요, 갑시다.)

(b) 가게에서
1. pasale ji, yo kaparaako kati ? / miTarko bis rupiyaa.
   (주인장님, 이 옷감 얼마인가요? / 미터당 20루피입니다.)
2. kasto mahanago ! ali sasto chhaina ? / chhaina, yo dherai raamro chha.
   (정말 비싸네요! 좀 더 싼 건 없나요? / 없어요, 이건 아주 좋은 겁니다.)
3. arkho hernos, tyo sasto chha. / tyo kasto chha ?
   (다른 걸 보세요, 저건 싸요. / 저건 어떤가요?)
4. tyo miTarko pandhra rupiyaa. / tyo tayaar garnus.
   (저건 미터당 15루피입니다. / 그걸로 준비해 주세요.)


3. PART II: PRACTICE (연습)
--------------------------------------------------
(a) 옷감 사기 (계속)
1. kati miTar lina ? / paach miTar.
   (몇 미터 살 건가요? / 5미터요.)
2. jammaa kati bhaayo ? / jammaa pachhattar rupiyaa bhaayo.
   (전부 얼마인가요? / 전부 75루피입니다.)
3. lau paisa. / dhanyabaad.
   (여기 돈 있습니다. / 감사합니다.)

(b) 물건 확인
1. yo ke ho ? / yo kaparaa ho.
2. tapaaïle kati miTar kaparaa kineko ? / maile paach miTar kineko.
   (옷감을 몇 미터 샀습니까? / 5미터 샀습니다.)
3. miTarko kati paisa ? / miTarko pandhra rupiyaa.
   (미터당 얼마입니까? / 미터당 15루피입니다.)

(c) 기분 표현
1. tapaaïlaai kasto chha ? / malaai dherai khusi chha.
   (기분이 어떠세요? / 아주 기쁩니다.)
2. kina ? / maile sasto kaparaa kine.
   (왜요? / 싼 옷감을 샀거든요.)


4. GRAMMAR NOTES (문법 정리)
--------------------------------------------------
1. mahanago / sasto: 가격이 비싸고 쌈을 나타내는 형용사입니다.
2. miTar: 옷감 등을 잴 때 사용하는 단위입니다.
3. ali: '조금', '약간'이라는 뜻으로 형용사를 수식합니다. (예: ali sasto - 조금 더 싼)
4. jammaa: 합계를 나타낼 때 사용합니다.
5. bhaayo: '되었다'는 뜻으로, 합계 금액을 말할 때 "전부 ~원입니다(되었습니다)"의 맥락으로 쓰입니다.
6. -aa/-o ending adjectives: 네팔어 형용사 중 'o'나 'aa'로 끝나는 것들은 수식하는 명사의 성/수에 따라 변하기도 하지만, 구어체에서는 주로 기본형을 많이 사용합니다.
