BASIC COURSE IN SPOKEN NEPALI - LESSON 39
==================================================

1. VOCABULARY (어휘)
--------------------------------------------------
anubhav        : experience (경험)
bites          : passed (time) (지나간/경과한)
daalnu         : to put into / to pour (넣다/붓다)
ghatanaa       : incident / event (사건/일)
hunu ta        : actually / although (사실은/그렇긴 하지만)
jhandai        : almost / nearly (하마터면/거의)
marnu          : to die (죽다)
samjhanu       : to remember (기억하다)
tarsinu        : to be frightened (깜짝 놀라다/겁나다)


2. PART I: DIALOGUE (대화문)
--------------------------------------------------
(a) 위험했던 순간의 기억
1. tapaai nepaalmaa hudaako kunai raamro ghatanaa samjhannuhunchha?
   (네팔에 있을 때 있었던 어떤 좋은 사건(기억)이 나나요?)
2. ho, ekpaTak ma jhandai mareko thié.
   (네, 한번은 하마터면 죽을 뻔한 적이 있었어요.)
3. ke bhayeko thiyo? / ma pahaaDbaaTa ladna laageko thié.
   (무슨 일이 있었나요? / 제가 산에서 떨어질 뻔했거든요.)
4. tyaspachhi ke bhayo? / saathile jhyaappai samaatyo ra baaché.
   (그 후엔 어떻게 됐나요? / 친구가 덥석 잡아줘서 살았습니다.)

(b) 음식에 대한 경험
1. nepaali khaanaa kasto laagyo? / malaai dherai miTho laagyo.
   (네팔 음식은 어떤가요? / 제 입맛에 아주 잘 맞아요.)
2. khorsaani dherai hunchha, hoina? / ho, pahile pahile ta saarhai piro laagthyo.
   (고추가 많이 들어가죠, 그렇죠? / 네, 처음에는 정말 매웠어요.)
3. ahile ni? / ahile ta baani paryo. khorsaani nahaali khaana man pardaina.
   (지금은요? / 지금은 익숙해졌어요. 고추를 안 넣으면 먹고 싶지가 않아요.)


3. PART II: PRACTICE (연습)
--------------------------------------------------
(a) '하마터면 ~할 뻔했다' (Jhandai)
1. hijo ke bhayo? / jhandai gaadi le kichyo.
   (어제 무슨 일이 있었니? / 하마터면 차에 치일 뻔했어.)
2. kina tyasto bhayo? / maile gaadi aaeko dekhina.
   (왜 그랬어? / 차가 오는 걸 못 봤거든.)

(b) 시간의 경과와 익숙함
1. nepaalmaa basna thaaleko kati bhayo? / chha mahinaa bhayo.
   (네팔에서 살기 시작한 지 얼마나 됐나요? / 6개월 됐습니다.)
2. nepaali bhaashaa bolna sajilo laagchha? / ahile ta sajilo laagna thaalyo.
   (네팔어로 말하는 게 쉬운가요? / 이제는 쉽게 느껴지기 시작했어요.)


4. COMPREHENSION (이해하기)
--------------------------------------------------
[내용 요약: 마이크는 네팔 생활에 완벽히 적응했습니다. 처음 네팔에 왔을 때는 길에서 소를 보는 것도 신기했고, 손으로 밥을 먹는 것도 어려웠지만 지금은 모든 것이 자연스럽습니다. 그는 지난주 트레킹 중에 길을 잃을 뻔한 아찔한 경험을 했지만, 지나가던 농부의 도움으로 무사히 숙소에 도착할 수 있었습니다. 그는 이 사건을 네팔에서 겪은 가장 잊지 못할 일로 기억합니다.]


5. GRAMMAR NOTES (문법 정리)
--------------------------------------------------
1. Jhandai (Almost / Nearly):
   - "하마터면 ~할 뻔했다"는 의미로, 일어나지 않았지만 거의 일어날 뻔한 위험한 상황 등을 묘사할 때 씁니다.
   - 예: jhandai gaadile kichyo (하마터면 차에 치일 뻔했다).
2. Baani parnu (To be accustomed to):
   - 습관이 들다, 익숙해지다라는 뜻입니다.
   - 예: malaai piro khaane baani paryo (저는 매운 것을 먹는 데 익숙해졌습니다).
3. ~na thaalnu (To start doing):
   - 어떤 동작이나 상태가 시작됨을 나타냅니다.
   - 예: bolna thaalyo (말하기 시작했다), sajilo laagna thaalyo (쉬워지기 시작했다).
4. Hunu ta (Actually / Although):
   - "사실은 말이죠", "그렇기는 하지만"과 같이 화제를 전환하거나 부연 설명을 할 때 사용합니다.
